## Sobre o projeto

O **LUMI** é a evolução do Sistema de Orçamento Automatizado (SOA), desenvolvido em fases anteriores do Projeto Integrador para o **Estúdio L'amore**, empresa especializada em papelaria personalizada para casamentos.

O objetivo do LUMI é consolidar, em uma única solução, a gestão operacional do negócio e a inteligência analítica sobre seus dados, resolvendo problemas como:

- Descentralização dos dados operacionais e de pedidos;
- Falta de métricas consolidadas sobre a experiência do cliente (CX) no pós-venda;
- Ausência de histórico estruturado para apoiar decisões estratégicas.

Para isso, o projeto implementa:

- **Data Warehouse relacional em PostgreSQL**, com modelagem multidimensional (Star Schema) para consolidar fatos e dimensões do negócio;
- **Módulo de avaliação de Customer Experience (CX)**, com formulários web para coleta de feedback pós-venda;
- **Painel analítico (Dashboard)**, com indicadores financeiros, operacionais e estatísticos para apoiar a tomada de decisão estratégica.

## Tecnologias

- **Banco de dados:** PostgreSQL
- **Backend / ETL:** Python, Pandas
- **Aplicação web:** Streamlit, HTML, CSS, JavaScript
